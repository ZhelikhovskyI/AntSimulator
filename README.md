# Симулятор Муравья (WPF)

Программа имитирует поведение муравья на двумерном поле. Пользователь может задавать правила поведения для белых и черных клеток, а также настраивать размер сетки.

## Функционал
- Настройка размера поля (от 5 до 100 клеток).
- Гибкие правила для белых и черных клеток (повороты, перекрашивание, движение прямо).
- Визуализация шагов муравья.
- Управление: Старт, Пауза, Сброс.

## Технологии
- C#
- WPF (.NET)
